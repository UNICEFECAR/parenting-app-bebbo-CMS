# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report them privately using one of the following channels:

- **GitHub private vulnerability reporting:** use the *Report a vulnerability* button under the repository's **Security** tab.
- **Maintainers:** contact the maintainers listed in the [README](README.md#maintainers).

Please include as much of the following as you can:

- A description of the vulnerability and its impact
- Steps to reproduce (affected endpoint, site, or module)
- Any relevant logs, screenshots, or proof-of-concept

You will receive an acknowledgement of your report, and we will keep you informed as the issue is triaged and fixed. Please allow the maintainers reasonable time to remediate before any public disclosure.

## Scope

This policy covers the Bebbo CMS codebase in this repository — the Drupal multisite, its custom modules under `docroot/modules/custom/`, and the REST APIs it exposes. Vulnerabilities in the Bebbo mobile apps or third-party (contrib) modules should be reported to their respective projects; if unsure, report here and we will redirect.
